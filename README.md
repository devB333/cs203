# Game Mechanics Unity Final Project
## Abstract
Our plan is to develop three separate game mechanics in Unity that we believe will be both interesting and challenging to create.  
The primary language utilized will be the engine-standard C#.

### Goals
- Learn basic utilization of the Unity Engine  
- Develop and implement custom C# for each mechanic  
- Create a test level to showcase each mechanic  
- Ensure each mechanic implements at least one data structure learned in CS203
